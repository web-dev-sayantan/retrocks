# Reopening closed Pointing Poker Rooms clears Participants and locks prior Stories

Closing a Pointing Poker Room wipes its Participant roster and Co-Facilitator Link so Display Names do not linger on closed summaries, keeping only Facilitator session hashes for deletion and reopening. When a Facilitator reopens a closed Room, those hashes become pending Facilitator claims so returning Facilitators and Participants re-enter through the Display Name join screen, a new Co-Facilitator Link is issued on demand, and every pre-close Story is marked as a Locked Story so the prior session's record stays protected until explicitly unlocked.
