# Participant-chosen names in Pointing Poker Rooms

Pointing Poker Rooms use a Display Name chosen by each Participant so the team can discuss individual estimates after reveal. Participants may enter a real name or an alias, and their choice is visible to others in that Room. This is a Room-specific exception to the retrospective Board policy of never asking for a display name, and joining still requires no account or personal profile.
